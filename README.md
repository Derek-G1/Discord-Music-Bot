# Discord-Music-Bot (Updated for discord.js v14)

A simple, updated music bot for Discord that plays audio from YouTube links.

## Features

- Plays audio from a YouTube URL in a voice channel.
- Built with the latest `discord.js` v14 and `@discordjs/voice`.
- Simple command structure.

## Commands

- `#play <youtube_url>`: Plays the audio from the provided YouTube link in your current voice channel.
- `#stop`: Stops the music and clears the queue.

## Setup

1.  Clone the repository.
2.  Run `npm install` to install all required dependencies.
3.  Create a `config.json` file with your bot's token.
4.  Run `node index.js` to start the bot.
